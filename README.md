# Day 25 — Detailed Error / Failure Analysis

## Run
Install `pandas`, `numpy`, `matplotlib`, `scikit-learn`, and `joblib`, then open `Day25_Error_Failure_Analysis.ipynb` in Jupyter or Colab.

Keep the frozen Day 22 model, Day 23 constant-mean baseline, and `water_potability_temporal_synthetic.csv` in the same directory.

## Contents
- Detailed notebook inspecting individual worst predictions and grouped error patterns
- Worst 20 test predictions
- All held-out test predictions with residuals and baseline comparison
- Error summaries by pH range, magnitude and direction
- Linear coefficient explanation
- Residual and prediction visualizations
- Technical report and limitation list

No model retraining or tuning is performed. Timestamps are synthetic; results are pseudo-temporal academic analysis only.
